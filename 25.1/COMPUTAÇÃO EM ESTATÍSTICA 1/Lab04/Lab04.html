Parte 1

Vocês irão trabalhar com alguns bancos de dados nesta avaliação. O banco de dados def_area_1988_2022.csv contém dados sobre a área desmatada (\(km^2\)), entre os anos de 1988 a 2022 para todos os estados da Amazônia Legal, organizados pelo Programa de Monitoramento da Floresta Amazônica Brasileira por Satélite (PRODES). O banco de dados inpe_brazilian_amazon_fires_1999_2022.csv contém registros da quantidade de focos de incêndio na Amazônia Legal por estado, mês e ano, de 1999 a 2022. O dados são geridos pelo Instituto Nacional de Pesquisas Espaciais (INPE) em seu programa Banco de Dados de Queimada (BDQ). O conjunto de dados el_nino_la_nina_1999_2022.csv contém dados sobre ano de início, ano de fim e severidade de dois dos fenômenos climáticos mais importantes El Niño e La Niña. Esses dados são organizados pelo Golden Gate Weather Services. Finalmente, o banco de dados br_presidents.csv contém os presidentes brasileiros, por ano, de 1988 a 2022. Este último banco de dados foi resumido em anos pelo Professor James de modo a possibilitar alguma análise anual, conjuntamente aos demais bancos de dados.

Utilize o comando abaixo para carregar o pacote tidyverse e carregar os quatro bancos de dados em objetos do R.

library( tidyverse )
def_area <- read.csv( "def_area_1988_2022.csv")
fires_amz <- read.csv( "inpe_brazilian_amazon_fires_1999_2022.csv", check.names = F, sep = ";" )
phenomenon <- read.csv( "el_nino_la_nina_1999_2022.csv", sep = ";" )
br_presidents <- read.csv( "br_presidents.csv", sep = ";" )

Parte 2

Vocês irão aprender aqui como adicionar, aos seus gráficos, linhas verticais por meio da geometria geom_vline e textos por meio do comando annotate. Lembre-se, para qualquer dúvida sempre há o help. O comando abaixo gera um gráfico de linhas ao longo do tempo com linhas verticais pontilhadas exatamente na troca dos governos. Além disso, adicionamos o nome dos presidentes que atuaram durante o período.

degradation %>%
  ggplot( aes( year, deforestation ) ) +
  geom_line() +
  geom_vline( xintercept = c(1990.33, 1993, 1995, 2003, 2011, 2016.67, 2019),
              color = "magenta", linetype = 3 ) +
  annotate( "text",
            x = c(1991.3, 1993.9, 1995.8, 2003.8, 2011.9, 2017.7, 2020.4),
            y = 31000, 
            label = c("Collor", "Itamar", "FHC", "Lula", "Dilma", "Temer", "Bolsonaro"),
            size = 2)

Parte 3

El Niño e La Niña são fenômenos climáticos importantes que podem afetar o regime de chuvas e, consequentemente, focos de incêndio e desmatamento. Nos exercícios seguintes, você irão realizar alguma análise, superficial, sobre esses fenômenos.

  1. Faça um boxplot do fenômeno contra as queimadas a partir de 1999. Isto porque não há dados anteriormente a essa data. O que você observa?

  2. Apresente um gráfico que resuma a relação entre os fenômenos ocorridos, a partir de 1999, por governo.

  3. Atribua o tipo factor à variável severity. Em seguida ordene os níveis da variável por meio do comando ordered. Consulte o help.

  4. Faça um boxplot da severidade contra as queimadas separado por fenômeno. Lembre-se que não há dados antes de 1999. O que você observa?

  5. Apresente um gráfico com a severidade de cada fenômeno, para cada governo, a partir de 1999. Para uma melhor visualização adicione os argumentos fig.height=4 e fig.width=10 ao chunk.
